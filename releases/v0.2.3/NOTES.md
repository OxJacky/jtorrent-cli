JTorrent 0.2.3 adds per-user Windows installation, verified cross-platform updates, a version command and installation-aware update notices. Windows releases are available for AMD64 and ARM64, alongside Linux and macOS releases.

Windows: `irm https://jtorrent.in/install.ps1 | iex`

Direct installs: `jtorrent update`. Homebrew installs: `brew update && brew upgrade jtorrent`.

Checksums are verified before installation. Updates preserve settings and downloads. Windows updates complete after the running process exits. Premium multi-connection support now includes Windows.
